Installer l'application

  1. Une fois le téléchargement terminé, appuyez sur Ouvrir (ou ouvrez COTIZI.apk dans le dossier Téléchargements).
  2. Si Android bloque l'installation : Paramètres → activez Autoriser à partir de cette source, puis revenez en arrière.
  3. Appuyez sur Installer. Si Play Protect affiche un avertissement : Plus de détails → Installer quand même.

L'installation échoue (« Application non installée ») ? Votre téléphone a peut-être besoin de la version pour anciens téléphones.
